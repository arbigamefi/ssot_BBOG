# Embedded Release Snapshots

This folder is the **single source of truth** for runtime contract addresses and module mapping.

## Policy (MUST)
- Snapshots are synced from a contract release bundle using:
  - `pnpm ssot:sync -- --from <releaseDir>`
- The UI must display `releaseDigest[:8]` for the active snapshot.
- If snapshot validation fails, the app must enter **read-only** mode.

## Structure
One JSON per chain, named `chain-<chainId>.json`, generated by `pnpm ssot:sync`.
