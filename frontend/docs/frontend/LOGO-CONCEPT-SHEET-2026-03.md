## 1. Purpose

This document narrows the first logo exploration to three viable directions.

It is meant to stop logo design from drifting into:

- generic crypto tokens
- literal casino clip-art
- over-ornamented esports branding

The goal of this first pass is not to finalize the logo.
The goal is to define the right exploration range.

---

## 2. Design Constraints

The logo must work in:

- browser header
- landing page hero
- wallet connection metadata
- favicon
- social avatar
- dark UI chrome

The mark must remain legible at:

- `16x16`
- `32x32`
- `64x64`

The system must support:

- icon-only
- wordmark-only
- horizontal lockup
- monochrome version

---

## 3. Recommended Direction

Recommended direction for the first serious pass:

`Direction A — Precision Monogram`

Why:

- strongest fit with premium product positioning
- easiest to keep credible on both landing and trust routes
- easiest to scale down for favicon and app icon
- avoids looking like a casual casino clone

---

## 4. Direction A — Precision Monogram

### 4.1 Core idea

Build a compact `AG` monogram with one orbital or rail-like gesture that suggests:

- motion
- edge
- controlled play

### 4.2 Visual character

- geometric
- crisp
- premium
- slightly kinetic

### 4.3 What it communicates

- product maturity
- precision
- brand confidence
- room energy without visual noise

### 4.4 Best use cases

- app icon
- header brand mark
- social avatar
- wordmark lockup

### 4.5 Risks

- can become too fintech if the motion gesture is too restrained
- can become generic crypto if the monogram is too abstract

### 4.6 Design note

The orbital gesture should feel like movement around a center of action, not a planet logo.

---

## 5. Direction B — Table Rail Emblem

### 5.1 Core idea

Create a crest-like mark that borrows from the silhouette of a game table rail or room frame, with `AG` embedded in the structure.

### 5.2 Visual character

- premium
- room-native
- darker
- more atmospheric

### 5.3 What it communicates

- room-first gameplay
- premium table product
- strong gaming context

### 5.4 Best use cases

- landing hero
- splash screens
- featured room branding

### 5.5 Risks

- easier to over-design
- harder to keep legible at favicon scale
- can drift toward “luxury casino badge” cliché

---

## 6. Direction C — Outcome Arc

### 6.1 Core idea

Build a minimalist mark around one decisive arc or strike that implies:

- result
- motion
- reveal

The wordmark would do more of the identity work than the icon itself.

### 6.2 Visual character

- modern
- editorial
- minimal
- product-led

### 6.3 What it communicates

- speed
- confidence
- product polish

### 6.4 Best use cases

- landing page
- editorial brand expressions
- high-end marketing surfaces

### 6.5 Risks

- less distinctive as an app icon
- may under-express the gameplay side of the product

---

## 7. Do Not Explore

Reject these directions up front:

- roulette wheel illustration logos
- dice pair logos
- coin-flip or token icons
- mascot logos
- cyberpunk glitch marks
- generic “A inside hexagon” crypto logos
- logos that require gradients to read

---

## 8. Wordmark Direction

The wordmark should read as:

- modern
- stable
- premium

Recommended characteristics:

- clean geometric sans
- modest custom cut or angle
- slightly tightened spacing
- no novelty display font

Emphasis should remain on `ArbiGameFi`, not on stylizing every letter.

---

## 9. Color Application

For the first logo pass, test only these variants:

1. light mark on dark surface
2. dark mark on light surface
3. single accent mark on dark surface

Do not start with multi-gradient logo artwork.

The gradient belongs to product surfaces, not to the logo core.

---

## 10. First Review Criteria

The first logo review should ask:

1. Does it read clearly at favicon size?
2. Does it feel like ArbiGameFi, not a generic token?
3. Does it support both room pages and trust pages?
4. Does it remain strong without glow or gradients?
5. Does it match the product thesis of premium play plus readable trust?

---

## 11. Immediate Deliverable Format

The first designer pass should deliver:

1. three directions only
2. one icon mark and one wordmark per direction
3. dark and monochrome previews
4. favicon-scale preview
5. one sample header application

Do not request a 20-logo exploration sheet.

---

## 12. Decision

The current recommended path is:

1. explore `Direction A` in detail
2. keep `Direction B` as the strongest alternative
3. keep `Direction C` only as a minimal fallback
