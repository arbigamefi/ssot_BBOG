# Historical Frontend Planning Archive

The markdown files in this directory are historical planning artifacts from the
pre-clean-room frontend. They are useful for context, but they are no longer the
active SSOT for frontend architecture, UI, or route decisions.

Active rewrite SSOT lives in:

- `docs/design/README.md`
- `docs/design/north-star.md`
- `docs/design/frontend-rewrite-blueprint.md`
- `docs/frontend/INDEX.md`
- `frontend/CLAUDE.md`

If a historical file conflicts with those documents, the new SSOT wins.
