# Frontend artifacts (required)

This repository produces **two required frontend artifacts** as part of the release workflow. The goal is
to make the frontend **zero-inference / zero-guessing** and allow encoding correctness to be tested with
**exact bytes equality**.

## 1) `deployments/frontend-manifest-latest.json`

A machine-readable manifest that the frontend should **consume directly**:

- `schemaVersion` (must match the frontend parser)
- `chainId`, `blockNumber`, `gitSha`
- `addresses` (hub/vrfHub/registries/modules/banks...)
- `games[]`: `{ gameId, slug, label, module, paramsEncoding }`
- `assets[]`: `{ asset, bank, symbol, decimals }`

Frontend rule: **copy + consume**. Do not derive `gameId` or token metadata.

## 2) `deployments/golden-vectors-latest.json`

Canonical bytes vectors generated by the contracts repo to prevent silent ABI mismatches.

Each vector includes:
- `params` (bytes)
- `stakeSpecEncoded` (bytes)
- `placeBetCalldata` (bytes)

Frontend rule: Vitest should do **exact hex equality** against your encoding helpers.

## Versioned copies

For reproducibility, each artifact is also written under:

- `deployments/release/frontend-manifest-<chainId>-<block>.json`
- `deployments/release/golden-vectors-<chainId>-<block>.json`

## How to generate

After `make deploy` produced `deployments/latest.json`:

```bash
make release-frontend-manifest
make release-golden-vectors
```


## ABIs

Releases ship a trimmed ABI directory at `abis/` inside the bundle. Frontend should load ABI JSON from there (do not embed ABI in source).
