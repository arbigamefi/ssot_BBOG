# H-1 前缀阈值优化：验证与落地

日期：2026-10-05。**优化已进入主工作区；正式发布仍为 REWORK。**
这是本轮实现验证，不是新增独立 Reviewer 裁决，也不是已部署版本认证。

## 改动与身份

生产只改 `LiquidityVault` 的前缀选择：沿用原整数分摊，以已累计金额和未决子树金额
判断是否覆盖仓位的最大 LP 亏损。下界已足够时返回真，上界严格不足时返回假；上界相等继续走。
利润和亏损仍共用同一分配域。原完整金额查询移到测试参照，不保留第二套生产查询。

40 层、2^40 个叶编号容量、最多 25 轮、NFT 冷却/同步退出、奖励规则、回调预算和失败恢复不变。
基线为 `d130b4de` 加既有 WIP；本轮没有把原有 390 条变更作为已验证发布补丁。
候选 Vault SHA256 为 `0776839cde33ed9a5440cc6c35bcfc4886d3d537f7abd40a7ba279ca779f2593`。
固定 native Solc 0.8.37、Cancun、viaIR、optimizer 500。

交接所述“47 项通过的整理版”未找到可认证独立源件。本轮从保存的初版重建整理候选并重新验证，
没有移用旧计数或把初版回调数字直接作为整理版验收。

## 实际结果

所有严格回调使用固定 Base Sepolia 区块 47,657,524 的真实 wrapper/USDC 本地 fork，
consumer 预算 2,447,746。每个输入独立 setup/test，首次失败即门禁失败；retry 成功不算通过。

| 验证 | 结果 |
| --- | --- |
| 原薄前缀＋新 L0/L1/L2＋玩家拒付失败输入 | 首次成功，2,156,147 gas，无 retry |
| 满 40 层后选择旧前缀，同样新奖励/拒付 | 首次成功，1,988,497 gas，无 retry |
| 满 40 层后回退全池，同样新奖励/拒付 | 首次成功，2,085,950 gas，无 retry |
| 既有回调矩阵，去除两个完全重复配置 | 94/94 首次成功，最大观测 2,147,106 gas，无 retry |
| 完整合约 unit/diff/invariant，PR profile | 481 通过，0 失败，0 跳过；invariant 256 runs/depth 256 |
| Vault 与分配域定向测试 | 61 通过，五项 fuzz 各 1,000 轮；是 481 项的子集 |
| 真实 wrapper 常规集成 | 4 通过，0 失败，0 跳过 |
| ABI 与体积 | 19 份 ABI 与基线/前端相同；Vault 15,492 → 15,544 bytes，体积门通过 |

合计 97 个不同严格回调输入通过。矩阵一项首跑因 RPC TLS 错误停在 setup，
相同源码/输入单独重跑通过；原失败与重跑日志均保留。上述 gas 是 wrapper 边界观测，
不含 proof/billing，不能直接与 consumer 预算相减来推算 Bank 余量。
满 40 层的夹具逐层断言不能提前决定，并断言最终选择结果；资金状态通过公开存取和历史结算生成。
空编号历史的压缩边界沿用原结构见证，不声称实际执行过万亿次存款或线上攻击。

复用测试有一项缺少 Router 绑定桩接口、且准备资金少 1 USDC；trace 确认后仅修正测试夹具。
修正前失败、主动中断的一次回归及格式化工具产生的测试语法错误均保留，未计为通过。
最终定向、全量与回调构建的关键合约 runtime 模板逐字节一致，测试期间各自源清单无漂移。
通过后按 SHA 校验落入一份生产文件和四份相关测试文件，保留其余既有 WIP。
主工作区直接重编译后，两项阈值边界测试通过。Vault 可执行字节码、ABI 和长度与受测候选一致；
依赖自动 remapping 的路径表示不同，仅使末尾 CBOR 内的 32-byte 元数据哈希不同，未冒称整个模板哈希相同。

## 剩余验收

整数等价性和最多 40 次分割已论证；满路径增加判断开销，不能继承旧 native CFG 的成本系数。
完整允许状态首次成功仍需把新 predicate、树写入、奖励/holdback、真实 token 分支及八模块
1–25 轮域合并到同一源码绑定预算，并逐层证明 EIP-150 转发、完成储备和 SSTORE sentry 余量。
当前成功样本没有完成这个证书。H-1 经济规则的既有独立结论与整个发布接受继续分开。
