## 范围与剩余审核意见

1. 本地视觉检查使用开发专用年龄/新手引导关闭开关。未替用户接受生产条款、连接钱包或发送交易；真实钱包拒签、网络切换中断、已连接资金状态及最终链上结算不由这轮无钱包检查证明。
2. /sportsbook 仍是预览且公开下注关闭。没有修改上线开关或把尚未启用功能描述为已验收。
3. /portfolio/activity 的未连接状态仍可进一步统一为显式钱包空状态；/portfolio/claims 还包含 XP、Holdback、治理费用等较重术语。后续产品化应把玩家说明与治理操作分开，避免本次样式调整扩大到领取业务重构。
4. 本地 /status 展示 stopped/stale keeper 并明确标注开发环境；不据此宣称生产故障。首页 reserve API 曾返回可重试读取失败，UI 保留失败提示及重试；本轮不修改 RPC/服务端策略。
5. 浏览器抽查覆盖布局与主要公开入口，不等于所有链、语言、钱包、交易状态组合的完整认证。此次没有引入支付/链上逻辑或部署配置变化。
