# Current audit scope

Status: the ADR-0034/0035 implementation and local validation are complete for the candidate commit
identified below. This is not a release approval. The candidate commit and its generated ABI set are
the input for external audit and fresh network acceptance.

The audit covers Bank asynchronous redemptions and player payables, SettlementRouter authority and
allocation caps, PoolRegistry isolation, GameHub admission and terminal paths, all admitted modules,
VRFHub/adapter fees and callbacks, referral registry and engine, and deployment/release validation.
The SDK, Earn UI, keeper and indexer must use the same contract model and preserve entitlement,
rounding, transaction identity, terminal recovery and reorg replay. Sports lifecycle and timeout
findings remain a separate admission gate; shared Bank changes do not close them.

Required evidence:

- Contract unit, differential and invariant suites; isolated casino admission gas tests.
- `test/unit/BankAsyncRedemption.t.sol`: cancellation until actual activation (also after eligibility),
  continuous betting with sufficient active capital, frozen pricing with newer holds still open,
  authorization, allocation, escrow, rounding, partial/full claims, player debt and solvency.
  Reconcile active and global reserves separately; isolated capital must not fund new risk, and
  pricing/claims must not repeat activation's share burn or charge settlement costs twice.
- `test/unit/ContractSizes.t.sol`: deployed runtime code respects EIP-170.
- `python3 test/mutation/v16_mutants.py --check` verifies mutation anchors only. A full mutation run
  (`python3 test/mutation/v16_mutants.py --out <evidence-dir>`) is distinct evidence and is valid only
  for the commit it ran on.
- SDK/keeper/UI tests, actual PostgreSQL bootstrap/recovery tests, and current ABI comparison.
- A fresh deployment's Safe, signer, bytecode/configuration and full batch lifecycle acceptance.

The Owner requires later exits to continue despite permanently stuck old positions, with old risk and
recovery rights preserved. Validate [ADR-0035](../adr/0035-recovery-rights-without-exit-blocking.md)
against the exact candidate source before final audit freeze or
external LP capital. Include historical rights after transfers/full exits, same-block snapshots,
multiple unfinished epochs, recovery cash-flow indexing, residual ownership and bounded operation costs.
Old-position terminalization has no maximum inclusion guarantee; it must not independently close new betting.
