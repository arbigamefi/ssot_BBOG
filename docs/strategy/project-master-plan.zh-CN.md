# ArbiGameFi 项目总纲

项目尚未上线。本总纲确定产品方向、资源排序与待验证假设；实现和发布边界见[当前规范](../constitution/SSOT.v1.6.md)与[发布说明](../release/README.md)。

## 产品命题

建设单品牌、钱包原生的 casino 与 sportsbook。娱乐体验是产品核心，可核对的规则、费用、结算和资本约束构成信任基础。品牌工作句是：**用自己的钱包参与游戏，看清每一次投入与结算。** 投注资金进入合约，钱包控制权不意味着资金始终留在钱包。

首批用户假设是：已有 EVM 钱包和稳定币经验的一部分成年人，会选择费用清楚、支付可核对的娱乐服务。该假设需要使用、回访和成本证据；代码与测试不等于需求验证。

## 已确定的范围

| 选择        | 当前方向                                                                         |
| ----------- | -------------------------------------------------------------------------------- |
| 产品形态    | 单品牌 B2C，首期不建设白标平台                                                   |
| 网络与资产  | 首期产品聚焦 Base 与 USDC，具体发布配置另行核实                                  |
| Casino      | 完成八类现有玩法的体验、结算和异常恢复                                           |
| Sportsbook  | 赛前足球 1X2 单关，独立赔率、结果、资本和准入                                    |
| Casino 分配 | 按实际流水计算理论 edge，LP 固定保留 50%，协议与推荐共享另一半                   |
| LP 进出     | 即时存入、异步请求；激活时定价现金，旧风险及回收权独立保留，新下注和后续退出继续 |
| 增长        | 先有限需求与经营验证，再扩大渠道和资本                                           |
| 资本关系    | LP 为指定池承担风险，不等于项目股权或固定收益产品                                |

没有有效推荐人时，未分配的运营预算及推荐舍入余数归协议；不改变 LP 固定份额。完整计算和成本校准见[经济设计](economic-design.md)。

## 交付顺序

1. 完成玩家从规则、报价、授权到结果与支付凭证的完整路径，保留不确定提交和异常恢复。
2. 验证资本账本、全部负债、异步退出授权、舍入、偿付和故障条件；页面准确区分 pending、claimable 和已付款。
3. 验证 keeper 的结算、超时退款、隔离、定价、重启恢复和告警，准备独立运行预算。
4. 完成当前发布所需的独立审查、配置与限定环境验收，再决定实际开放范围。
5. 按预设指标开展有限使用和渠道验证；根据真实需求及贡献决定扩容。

体育规则、数据和风险研究可并行，但体育终结期限未完成前不准入异步 Bank。资金安全或恢复缺陷优先于新增玩法和增长工作。

## 经营判断

玩家总支出包含游戏成本、gas 与随机数费用。LP 收益取决于资本占用、结果波动及费用留存。运营预算必须覆盖 keeper、基础设施、维护和支持。渠道成本需要真实使用和回访贡献支撑。补贴、捐赠和 LP 入金分别核算，不以流水掩盖亏损。

不预设 APY、回本期、市场份额或融资估值。若玩家成本过高、资本补偿不足或服务预算无法持续，应调整范围和成本；不能用宣传替代缺失的证据。

## 验证假设

| 假设                 | 所需证据                                               |
| -------------------- | ------------------------------------------------------ |
| 目标用户偏好组合体验 | 实际任务、放弃原因、无补贴回访                         |
| 目标金额可承担成本   | 各玩法 gas、VRF、等待和恢复成本                        |
| LP 愿意承担风险      | 完整损益分布、集中退出及旧仓长期未终结情景、参与者理解 |
| 渠道带来有效使用     | 可核对归因、实际成本、固定窗口回访与贡献               |
| 体育具有独立需求     | 赛事使用场景、数据成本及独立资本经济性                 |

观察需标明招募方式、样本范围、是否补贴和时间窗口；不得把少量反馈说成总体需求或资金承诺。
